# PEC2 de Visualización de Datos del Máster de Ciencia de Datos de la UOC

Ejercicio de visualización de datos realizado a partir de conjuntos de datos abiertos de administraciones públicas. Se presentan tres técnicas de visualización, cada una con su definición, el tipo de datos que requiere y un comentario sobre lo que muestra.

**Estructura**:

- [GRUPO I - Técnicas básicas y populares: Dot Density Map](grupo1.md)

- [GRUPO II - Técnicas habituales y específicas: Linear dendrogram](grupo2.md)

- [GRUPO III - Técnicas menos habituales o más específicas: Rose Chart](grupo3.md)
